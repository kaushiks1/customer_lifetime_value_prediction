# Project Summary: Customer Lifetime Value Prediction

## Objective

Predict future 12-month customer lifetime value using ecommerce, marketing, engagement, and digital analytics features.

## Business Context

Not all customers have equal future value. CLV prediction helps businesses prioritize retention, acquisition, personalization, and marketing budget allocation.

## Methodology

1. Generate realistic customer and transaction-level ecommerce data.
2. Create customer-level features such as recency, frequency, AOV, revenue, margin, web engagement, and churn risk.
3. Train a Random Forest Regressor to predict future 12-month CLV.
4. Evaluate model performance using MAE, RMSE, and R².
5. Score every customer with predicted CLV.
6. Group customers into CLV tiers.
7. Create marketing recommendations for each tier.

## Business Value

- Better CRM targeting
- Improved retention strategy
- More efficient paid media spend
- Reduced discount waste
- Better acquisition channel quality measurement
- Stronger customer lifecycle strategy
